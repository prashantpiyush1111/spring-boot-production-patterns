# Contributing to Spring Boot Production Patterns

Thank you for your interest in contributing! 🎉

## How to Add a New Pattern

1. Fork this repository
2. Create a new folder: `XX-pattern-name/`
3. Inside your folder add:
   - `README.md` — explanation + diagram
   - `src/` — Spring Boot code
   - `docker-compose.yml` — Docker setup
4. Create a Pull Request

## Folder Structure for Each Pattern

XX-pattern-name/
├── src/
│   └── (Spring Boot project)
├── README.md
└── docker-compose.yml

## Guidelines

- Java 17+ use karo
- Spring Boot 3.x use karo
- Har pattern ka Docker setup hona chahiye
- README mein diagram zaroor hona chahiye

## Good First Issues

Check issues labeled `good-first-issue` for beginner friendly tasks.
